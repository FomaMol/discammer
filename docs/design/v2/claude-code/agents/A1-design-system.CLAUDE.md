## Rules
- One chromatic accent (cyan) + semantic amber/green/red. No purple, no second accent, no gradient.
- Shadows always tinted canvas-blue, never pure `#000`. Cards earn elevation by role, not by default.
- Texture: `--grain` on `code-bg` wells only; grid-40 on hero/game/CTA-band; never behind body text.
- Section rhythm must alternate temperature (loud→quiet→loud); let ONE feature break the container.
- Keep `DESIGN.md` and `globals.css` in lockstep — they are one artifact in two files.

## Hard reject
Cadence Design System styling (indigo/Onest/violet, 12–16px planner radii, soft pastel surfaces). It
is a different product's brand. DiScammer is the dark cyan analyst console — defend it.
