# CLAUDE.md — A2 Type & Fonts · A4 Motion & Graphics · A5 Copy & i18n · A6 QA

Four lean briefs. Each agent owns one layer and the skills noted.

---

## A2 — Type & Fonts
**Skill:** fonts.google.com.
- Self-host **Geist** (400/500/600) + **JetBrains Mono** (400/500/600/700/800), full Cyrillic, via
  `@font-face` + `font-display:swap` + preconnect in `base.html`. Remove any Inter/pixel loader.
- Implement the **two-register rule** as `.t-data` (mono) / `.t-editorial` (Geist) utilities so
  components can't mix faces by accident.
- **Accept:** body is true Geist Cyrillic (not fallback); Latin/Cyrillic x-height parity at 24px; no
  render-blocking font; no CLS from swap.
- **Reject:** Onest (that's Cadence's UI face, wrong product). DiScammer display voice is JetBrains Mono.

## A4 — Motion & Graphics
**Skill:** dgreenheck/webgpu-claude-skill.
- Own hero/game ambient canvas (grid + ≤18 drifting squares + slow scan), staggered reveals, meter
  fill, progress bar. Three tiers: ambient / entrance / feedback. GPU-only (`transform`/`opacity`).
- **WebGPU spike (T3.2):** evaluate a gated, reduced-motion-safe WebGPU hero field. Ship ONLY if it
  stays ≤ the game's intensity and degrades to Canvas2D cleanly. Default stays Canvas2D — the web is
  the *quieter* surface; don't out-game the game.
- **Accept:** `prefers-reduced-motion` makes canvas static, reveals snap, zero infinite loops. No jank.

## A5 — Copy & i18n
**Skill:** authored writing (PRODUCT.md voice: vigilant, plain-spoken, technically grounded).
- Every new v2 string lives in **both** `en.json` and `ru.json`, **authored** (RU is not a literal
  translation). Forbidden words: delve/seamless/elevate/unleash/next-gen/"in the world of". No em
  dashes in body. Dynamic keys referenced literally per branch or added to `i18n_allowlist.txt`.
- Own: three-ways band copy, checker label + result copy (soften clean state: "not the same as safe"),
  action-module CTAs, stat-truth numbers.
- **Accept:** `i18n_audit.py` 0 dead / 0 missing / en==ru keys; reads native in both languages.

**Skill:** microsoft/playwright-cli.
- Run the full gate in `03-verification.md` on every PR; author the v2-specific specs (checker,
  inspector, meter-grayscale, three-ways, focus-skiplink, no-ab-switcher, reduced-motion, i18n-parity,
  cyrillic-layout, perf).

- **Accept:** all gates green; red bounces to the owning agent with the failing artifact attached.
- **Brand-lock static check:** fail CI on `#00F0FF`, any purple/violet hex, second accent, gradient-
  text, pixel font, Inter, or Cadence component imports.
